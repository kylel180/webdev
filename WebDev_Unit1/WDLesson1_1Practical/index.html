Web Technologies

HTML

HTML is the standard language used to create and structure content on the web such as websites or browsers and is like the skeleton of websites. HTML works with CSS to make the website look good with colors and fonts, HTML gives the websites functions. HTML is required for a website to process otherwise the computer has no code to run.

CSS

CSS is a stylesheet language used alongside HTMl to give a website its style, font, text colors and much more. CSS is what decorates websites and makes them look colorful. CSS also has animations and relies on HTML to work otherwise CSS has nothing to work with.

JavaScript

JavaScript is a scripting language that enables you to create dynamically updating content, control multimedia, animate images, and pretty much everything else. JavaScript does everything else CSS and HTML dont do and all three work together to run a website. Without these three a website cannot run by itself with no code at all.
